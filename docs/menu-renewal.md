# 인벤토리 메뉴 리뉴얼

기준 문서는 [원본 초안](specs/menu-renewal-v1.txt)과 제공된 배치 이미지입니다. 레벨·시간·맥박·통계는 대화에서 확인된 기준을 적용합니다.

## 화면과 카테고리

플레이어 인벤토리, 시체, 개인 창고, 휴대 가방, 무기 케이스/보관함은 동일한 화면 기준 외곽선을 사용합니다. 내용물은 가로·세로를 같은 비율로 맞춰 중앙에 배치하며 남는 공간을 여백으로 둡니다. 좌표 변환은 그리기·클릭·스크롤·툴팁에 함께 적용합니다. 외곽선 안의 여백을 클릭하는 것은 창 밖으로 아이템을 버리는 동작으로 취급하지 않습니다.

상단 6개 메뉴는 E로 여는 플레이어 인벤토리에만 있습니다. 새로 열 때마다 장비가 기본이며 창고·시체·가방·케이스에는 이 메뉴를 추가하지 않습니다. 크리에이티브의 Minecraft 인벤토리 전환 버튼은 유지합니다. 기존 창고 무기 분류 버튼은 별개의 기존 기능입니다.

- 종합정보: 캐릭터 정면 표시, 드래그 360도 회전, 레벨/등급/이름, 중요 정보 3개와 상세 통계.
- 장비: 왼쪽 무기, 중앙 캐릭터와 방어구, 캐릭터 아래 바이탈, 오른쪽 주머니/가방/보안 컨테이너. 바이탈의 상태 목록 전환 버튼은 유지합니다.
- 건강상태: 왼쪽 큰 바이탈과 스태미나, 캐릭터 아래 항상 보이는 상태 목록, 오른쪽 기존 보관 영역. 상태 목록을 여닫는 버튼은 없습니다.
- 스킬·퀘스트·도전과제: 중앙에 '개발중'만 표시합니다.

건강상태의 체온은 36.6°C, 감염·방사능은 0/100의 표시용 값입니다. 맥박은 체력 단계에 따라 66/108/156 BPM을 기준으로 ±2 정도 변화하며, 실제 게임 효과나 혈압 기능을 추가하지 않습니다.

## 레벨과 생존 등급

## 맵별 저장과 시간

맵은 월드 세이브 단위입니다. 같은 세이브의 차원 이동은 기록을 유지하며 다른 세이브는 별도입니다. 서버 월드의 SavedData `minecrafteft_profiles`에 UUID별로 저장하고 본인의 기록만 해당 클라이언트에 동기화합니다. 사망·재접속에도 누적 기록과 레벨은 유지됩니다.

- 캐릭터 만든 지: 기능 적용 후 최초 접속부터의 실제 경과 일수. 오프라인도 포함합니다.
- 생존 기간: 최초 접속 또는 마지막 사망 이후 살아서 접속한 틱만 누적합니다. 사망하면 0으로 초기화합니다.
- 맵 접속 시간: 해당 월드에 접속한 틱만 누적합니다. 오프라인과 일시정지된 싱글플레이 시간은 포함하지 않습니다.

이전 기록을 임의로 역산하지 않습니다. 기존 플레이어도 기능 적용 후부터 새로 집계합니다.

## 상세 통계 9개

1. 캐릭터 생성 날짜: 최초 기록 생성 시각.
2. 생존 등급: 독립 레벨 구간.
3. 치료한 체력 총량: 독립 체력 시스템에서 실제 회복된 양. 중간 취소 전 회복량도 실제 회복량이므로 포함합니다.
4. 골절 횟수: 새 부위에 발생한 골절마다 1. 같은 부위 중복, 재접속, 상태 복원은 제외합니다. 관리자 골절 명령으로 새 부위가 발생한 경우에도 반영됩니다.
5. 탈수 횟수: 탈수 상태가 새로 활성화될 때 1. 지속 중 매 틱 증가하지 않습니다.
6. 음료 섭취 횟수: 마시는 아이템의 사용 완료마다 1.
7. 음식 섭취 횟수: 먹을 수 있는 음식의 사용 완료마다 1. 아날긴은 음식으로 집계하지 않습니다.
8. 의약품 사용 횟수: AI-2·IFAK·부목·아날긴의 완료마다 1. 중간 취소는 제외합니다.
9. 이동 거리: 바닐라 직접 이동 통계의 신규 증분을 km로 환산합니다. 이전 누적값·순간이동·탑승 이동은 포함하지 않습니다.

## 낙하 골절 수정

높이별 발생 확률은 유지하면서 낙하 골절은 다리로만 결정합니다. 이미 다리가 골절되어 있으면 팔에 골절을 추가하지 않습니다. 일반 피격의 부위 선정 규칙은 유지합니다.

## 확인 범위

Java 컴파일과 배포용 JAR 생성, YSM 실행 폴더 준비를 확인합니다. 게임 실행·GameTest·기능 테스트는 수행하지 않습니다. 실제 해상도별 배치, YSM 모델 표시·회전, 서버 재접속 후 통계, 장비/가방/시체 클릭은 사용자가 게임에서 확인합니다. 네트워크 규약 16을 사용하므로 서버와 클라이언트 빌드를 맞춥니다.

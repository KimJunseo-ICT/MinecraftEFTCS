# AI-2 응급 치료 키트 시제품

- 아이템: `minecrafteft:ai2_medikit`. Minecraft EFT 크리에이티브 탭 또는 `/give @s minecrafteft:ai2_medikit`으로 꺼냅니다.
- 이름 색상은 `#b8d9bd`이며 크리에이티브 탭의 **치료 도구** 카테고리에 표시합니다. 카테고리는 제공된 아이콘으로 구분하고 커서를 올리면 이름이 나옵니다.
- 우클릭을 **유지**하면 6초 사용합니다. 음향은 별도로 추가하지 않았습니다.
- 0~3초: 키트를 꺼내 열고 주사 도구를 꺼낸 뒤 반대편 팔에 꽂습니다.
- 3초 시점: 내구도 1을 즉시 소모합니다. 최대 내구도는 5이며, 크리에이티브에서도 같은 소비 규칙을 적용합니다.
- 3~5초: 서버에서 매 틱 0.5 HP, 총 40틱 동안 **20 HP**를 점진적으로 회복합니다. 독립 체력의 최대값 100을 넘지는 않습니다.
- 5~6초에는 주사기를 빼서 버리고, 사용한 손으로 케이스를 다시 잡아 화면 아래로 내립니다.
- 사용이 끝난 뒤 0.3초(6틱) 동안 케이스를 다시 들어 올립니다. 처음 들고 있던 높이에 도달하면 다음 치료를 시작할 수 있습니다. 우클릭을 계속 누르거나 반대 손의 AI-2로 바꿔도 같은 대기가 적용됩니다.
- 준비 중 우클릭을 떼거나 아이템을 교체하면 내구도 소비 없이 취소합니다. 치료 중 취소하면 이미 회복한 체력만 유지하며 사용 횟수는 반환하지 않습니다.
- 준비·치료·정리 중 어느 시점에 취소해도 종료 시점부터 0.3초(6틱)의 재사용 대기시간을 적용합니다. 다른 AI-2나 반대 손으로 교체해도 이 대기는 유지됩니다.
- 다섯 번째 사용은 남은 껍데기를 종료까지 유지해 치료가 끊기지 않도록 했습니다. 사용 완료 또는 중도 취소 시 다 쓴 키트를 제거합니다.
- 사용 중에는 달리기와 점프를 막으며 일반 걷기와 정지는 가능합니다. 주 손과 보조 손 모두 지원하고, 왼손잡이 설정에서는 모션 방향을 반전합니다.
- 1인칭에서는 반대 손이 케이스를 받치고 사용 손이 아래쪽 걸쇠를 들어 뚜껑을 화면 위로 젖힙니다. 경첩은 케이스 상단에 있습니다. 트레이에 보이는 주사기를 그대로 들어 올리고, 키트를 쥔 팔을 내밀면서 바늘을 맞춥니다. 주입 중에는 팔의 미세한 움직임을 따라가며, 끝나면 같은 방향으로 빼서 옆으로 던집니다.
- 바늘 끝의 접점은 기본형·슬림형 스킨의 팔 너비와 소매 표시 설정을 반영합니다. 케이스와 주사기 형상은 처음 한 번 구성하고, 닫혀 있는 동안에는 내부 약품을 그리지 않습니다. 인벤토리와 3인칭에서는 닫힌 모델을 사용합니다.
- 케이스 겉면은 황토색 단차 테두리, 마름모 받침 위의 양각 십자와 하단의 가로 리브 세 줄로 구성합니다. 겉면과 안쪽에는 문자를 사용하지 않습니다. 영상의 사운드나 게임 원본 모델·애니메이션을 추출해 넣지 않았습니다.

## 확인 범위

`tools/checks/Ai2TreatmentCheck.java`는 치료 시간, 내구도 소모, 중도 취소와 손 위치의 연속성을 검사합니다. `tools/checks/Ai2GeometryCheck.java`는 경첩의 회전 경로와 트레이에서 꺼낸 주사기의 위치, 양손·스킨 너비·소매 설정별 바늘 접점을 검사합니다. `tools/Preview-Ai2Motion.py`는 게임에서 사용하는 모션을 읽어 자세별 실루엣을 만듭니다.

Minecraft 1.20.1과 Forge 47.4.28 개발 클라이언트에서 AI-2 사용을 재생하고 열기, 꺼내기, 주입, 회수 장면을 확인했습니다.

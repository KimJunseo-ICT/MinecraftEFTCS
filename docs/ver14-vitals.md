# ver14 바이탈 변경 사항

- 최대 체력 **100 HP**. ver13의 200 HP 저장 데이터는 남은 비율을 유지해 한 번 변환합니다. 예: 160/200 → 80/100. 에너지·수분·스태미나는 보존합니다.
- 에너지 또는 수분이 고갈되면 **3초 후 첫 피해**, 이후 **3초마다 피해**를 받습니다. 기본 피해는 고갈된 자원 하나당 1 HP, 둘 다 고갈이면 2 HP입니다. 둘 다 다시 양수가 되면 피해 대기 시간을 초기화합니다. 재접속·차원 이동은 진행 중인 피해 대기 시간을 보존합니다.
- 스태미나 **15% 이하 빨강**, **15% 초과 파랑**. 이미 진행 중인 달리기는 빨강으로 바뀌어도 계속할 수 있습니다. 걷거나 멈춘 뒤 새로 달리려면 15%를 초과해야 합니다. 0에서는 진행 중인 달리기도 중단합니다.
- 이동 정보가 잠시 없는 틱만으로 진행 중인 질주를 중단하지 않습니다. 재질주 제한은 실제 질주 시작·종료 상태로 판단합니다.
- 화면에 보이는 게이지는 서버 값 사이를 0.25초 동안 보간해 움직입니다. 표시용 보간은 피해나 달리기 판정을 늦추지 않습니다.
- 우측 하단 체력·에너지·수분을 막대 게이지로 변경하고 중앙에 %를 표시합니다. 이 세 막대는 스태미나 막대 길이의 78%, 높이 8픽셀입니다. 스태미나는 높이 12픽셀이며 %를 표시하지 않습니다. 화면 크기에 따라 너비를 조정합니다.

## 서버 설정

해당 월드의 `serverconfig/minecrafteft-server.toml` 아래 `[vitals]`:

- `deprivationDamageIntervalSeconds = 3.0`
- `emptyEnergyDamagePerPulse = 1.0`
- `emptyHydrationDamagePerPulse = 1.0`

이전 `emptyEnergyDamagePerSecond`·`emptyHydrationDamagePerSecond` 대신 위의 회당 피해 설정을 사용합니다. 소모 속도·음식 회복 등 나머지 설정은 유지합니다.

크리에이티브·관전의 자원 소모 제외와 기존 음식·물병·물약 호환 동작은 유지합니다. 게임 실행 없이 계산·상태 전환·표시 보간을 검사하며, 게임 내 시각 및 연동 검사는 직접 확인해야 합니다.

## 후속 HUD 배치 수정

TACZ 무기·탄약 표시와 겹치지 않게 네 게이지를 모두 좌측 하단에 세로 정렬했습니다. 전체 패널의 반투명 검은 배경은 제거했습니다. 네 막대는 같은 크기(기본 66×6 GUI 픽셀, 작은 화면에서는 너비 축소)이며, 텍스트 대신 `statusicon.zip`에서 제공된 네 투명 PNG 아이콘을 그대로 사용합니다. 체력·에너지·수분의 중앙 %와 스태미나의 % 없는 표시는 유지합니다.

현재 배치에서는 플레이 화면 좌측 하단을 체력·스태미나 두 줄로 줄였습니다. 스태미나는 이전 에너지 위치인 체력 바로 아래에 표시합니다. 에너지·수분은 아이콘과 함께 전용 인벤토리의 확대한 바이탈 창으로 옮겼습니다. 이 창은 심전도, 현재/최대 체력, 체력 바, 에너지 바, 수분 바 순서이며 체력·에너지·수분에 %를 표시합니다. 플레이 화면 게이지 크기는 44×6 GUI 픽셀이고 체력·스태미나의 기존 보간을 유지합니다.

두 줄은 채팅 이력과 입력창 사이 공간에 고정하며, 좁은 화면에서 길이를 줄여 핫바와의 간격을 확보합니다. 채팅과 플레이 화면에서는 채팅보다 앞에서 그립니다. 인벤토리 파형은 안정·주의·위험에서 박동 속도와 모양이 뚜렷하게 달라지고, 위험 상태는 간격과 강도가 변합니다. 화면용 파형 변화는 실제 체력 계산에 영향을 주지 않습니다.

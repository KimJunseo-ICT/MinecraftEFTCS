# 메뉴 리뉴얼 초안 ver1
- 인벤토리 창 메뉴를 전체적으로 통일하고 리뉴얼하기 위한 초안이다.

# 인벤토리 UI 사이즈 통일
- main_menu.png 의 빨간색 사각형 구역의 크기를 참고하여 플레이어 인벤토리 UI, 시체 파밍 시 인벤토리 UI, 개인 창고, 가방, 보관함 열람 시 인벤토리 UI 사이즈를 빨간색 사각형 구역의 크기에 맞춰 재배치 해아한다. 남는 공간을 여백으로 남겨두는 선택지도 충분히 활용할 가치가 있다.
- 이때, 각 구역당 충돌이 일어나지 않게 기존 설정을 유지하고 정렬이 잘되게, 한쪽으로 UI가 쏠리지 않도록 중앙 정렬을 지킨다.

# 인벤토리 메뉴 카테고리 목록 추가
- menu_bar.png는 원본 타르코프의 UI다. 좌상단 빨간색 사각형 구역에 있는 카테고리들이 이번에 구현해야할 클릭할 수 있는 인벤토리 메뉴 카테고리 버튼이다.
- main_menu.png에선 연두색 상자 영역에 배치한다고 보면 된다.
- [중요] : 이 카테고리 선택은 '플레이어 인벤토리'에서만 확인할 수 있다. (즉, E키를 눌러 나오는 인벤토리에서만 확인이 가능하며, 개인 창고, 가방, 보관함, 시체 상호작용시 나오는 UI에서는 인벤토리 메뉴를 사용할 수 없다.)

# 인벤토리 메뉴 카테고리
- 총 6개의 카테고리를 넣는다. 일부 기능은 이번 메뉴 리뉴얼 초안에서는 구현하지 않기 때문에 카테고리 구현만 해도 되는건 아래 따로 명시한다. 인벤토리 UI 사이즈 통일한 것에 맞춰 작업할 것.

1. 종합정보 (menu1.png의 원본 타르코프 UI 참고)
- 플레이어가 서버에서 활동한 전체적이 내용이 기록되고 열람할 수 있는 카테고리이다.
- 각 맵마다 플레이어들은 개인의 종합정보를 가진다.
- 빨간색 사각형 구역은 캐릭터의 최소한의 정보를 넣는다. 들어갈 정보는 다음과 같다
	-> 파란색 사각형 구역 : 캐릭터의 모델링이 표기된다. 기본은 정면 스탠딩으로 표기되며 이 상태에서 캐릭터를 누르고 좌우로 드래그할 시, 캐릭터자 좌우로 돌아가 측면, 후면도 볼 수 있게 360도 회전을 지원한다.
	-> 하늘색 사각형 구역(좌상단) : 캐릭터의 레벨과 그 레벨대에 맞는 '생존 등급 앰블럼'이 표시된다. 좌측에 엠블럼을 두고 엠블럼의 우측에 엠블럼 높이만큼의 픽셀 숫자로 레벨을 표시한다. (한자리 수의 경우 앞에 0을 붙인다.)
	    이때 레벨 구간과 생존 등급은 다음으로 나눈다. 1~10(초보자, 1_level.png 사용), 11~20(풋내기, 2_level.png 사용), 21~30(생존자, 3_level.png 사용), 31~40(수색꾼, 4_level.png 사용), 41~50(전문가, 5_level.png 사용), 51 이상(베테랑, 6_level.png 사용)
	-> 하늘색 사각형 구역(중앙하단) : 유저 닉네임을 표기한다. 그리고 그 아래는 YSM 모델 이름을 닉네임보다 조금 작은 크기로 표기한다. (YSM을 사용하지 않는 경우에는 공란으로 비운다.)
- 노란색 사각형 구역에는 캐릭터가 맵에서 활동안 종합 정보 중 중요한걸 담는다(종합정보만 남긴다. 'PMC', '스캐브'는 필요없다). 현재는 어떤걸 넣어야 할 지 미정이기에 일단 공간을 만들면 안에 넣을 정보는 '캐릭터 만든지'(맵에서 캐릭터를 생성한지 며칠 지났는지), (생존 기간(마지막 사망 시기를 기점으로 얼마나 지났는지), 플레이 시간(플레이 타임은 얼마인지) 이 세가지를 임시로 넣는다.
- 초록색 사각형 구역에는 캐릭터가 서버에서 활동한 내역중 상세하게 드러낼만한 것들의 통계이다. 여기에서도 임시로 넣을 것만 넣는데 여기서 넣을 건 초록색 사각형 구역 안에 있는 연두색 사각형 구역 안에 있는 것들만 넣는다.

2. 장비 (menu2.png에 새로 배치한 구상에 맞게 합성해봤음. 참고해서 UI 작업할 것.)
- 지금까지 만든 플레이어 인벤토리 UI에 대응하는 카테고리 목록이다. 새로 배치된 위치를 확인하고 글씨 및 아이템 이미지가 찌그러지지 않게 새로 배치한 이미지에 맞도록 최적화해서 수정할 것.
- [중요] E 키를 눌러 인벤토리를 열면 무조건 카테고리 중 장비 카테고리가 기본으로 선택되어야 한다. (크리에이티브에서 플레이어 인벤토리를 열 때 뜨는 'Minecraft 인벤토리로 전환' 버튼은 크리에이티브 일 시에만 뜨게 하는건 유지한다.)

3. 건강상태 (menu3.png에 새로 배치한 구상에 맞게 합성해봤음. 참고해서 UI 작업할 것.)
- 플레이어의 건강 상태를 확인할 수 있다. 장비 카테고리 UI와 비슷하지만 차이가 있다. 새로 배치된 위치를 확인하고 글씨 및 아이템 이미지가 찌그러지지 않게 새로 배치한 이미지에 맞도록 최적화해서 수정할 것.
- 좌측에 신체 상태와 관련된 정보를 넣는다.
- 여기서 파란색 사각형 구역은 실시간 스테미나의 현재량 / 최대량 및 % 게이지바가 들어가는 것으로 상세히 표기된다.
- 또한 체력 현황 숫자와 스테미나 현황 숫자 왼쪽에 각각의 아이콘을 넣는다.
- 연두색 구간에는 아직 미구현 기능이지만 표기만 해둔다. 좌상단 : 체온, 우상단 : 최대맥박/최소맥박, 좌하단 : 감염수치, 우하단 : 방사능 수치 이고 이미지에서의 짙은 배경은 없어도 된다.
- 맥박은 바이탈 3단 상황에 맞게 인간의 표준 맥박수를 각각의 상황에 맞춰 숫자가 변하도록 한다. (기능은 아직 없지만 일단 숫자가 변하는 시각적 효과만 넣는것)
- 또한 건강 상태 카테고리 내에서는 상태이상을 확인하는 버튼이 없어진다. 대신 캐릭터 하단(주황색 사각형 영역)에 버튼을 누르지 않아도 표기되는 거로 한다.

4. 스킬 (미구현 기능으로 아무것도 없는 창에 '개발중' 만 가운데에 적어둘 것)

5. 퀘스트 (미구현 기능으로 아무것도 없는 창에 '개발중' 만 가운데에 적어둘 것)

6. 도전과제 (미구현 기능으로 아무것도 없는 창에 '개발중' 만 가운데에 적어둘 것)
